## Capture checklist

- Maximum duration: 2:00. Capture actual UI at 1080p with readable browser zoom and no personal inboxes or credentials visible.
- Use a clean account and authorized, legally redistributable media. Never include the local Mentalist MKV.
- Hide browser password managers, notifications, API keys, personal data and internal dashboards.
- If a flow is unavailable, omit that scene and state the limitation in the narration rather than using a mockup.
- Export MP4 and keep a backup copy in the offline finale folder after recording.
