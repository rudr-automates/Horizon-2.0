# Synthetic fixture package

Everything in this folder is invented local test content for Horizon 2.0
acceptance testing. It is not a transcript, deck or recording of any real
course.

| File | What it is |
| --- | --- |
| `spaced-repetition-demo.mp4` | 60-second generated MP4 (ffmpeg `testsrc2` + tone) with a burned-in label naming it a synthetic demo lesson. |
| `spaced-repetition-demo.vtt` | WebVTT caption track written to match that video, ten cues across 00:00–01:00. |
| `spaced-repetition-practice.pptx` | 3-slide educational deck with speaker notes, generated by `scripts/build-fixture-package.py`. |

Regenerate the deck with:

```
python scripts/build-fixture-package.py
```

Regenerate the video with ffmpeg:

```
ffmpeg -f lavfi -i "testsrc2=size=640x360:rate=30:duration=60" \
  -f lavfi -i "sine=frequency=330:duration=60" \
  -c:v libx264 -pix_fmt yuv420p -crf 30 -preset veryfast \
  -c:a aac -b:a 48k -shortest spaced-repetition-demo.mp4
```

Use them to exercise local video upload, caption association, PPTX extraction
with slide provenance, and timestamp-grounded tutoring on a private lesson.
